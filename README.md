# 🚀 PPC Growth Lab - Amazon Agency Landing Page

A high-performance, futuristic landing page designed for an Amazon Growth Agency. This project showcases modern UI/UX principles, lead-generation strategies, and full responsiveness.

## ✨ Features
- **Modern Dark UI:** Neon accents and glassmorphic components.
- **Data-Driven Roadmap:** A 4-step process visualization for client success.
- **Lead Generation:** Optimized "Free Audit" form for high conversion.
- **Full Responsiveness:** Tailored layouts for Desktop, Tablet (1024px/768px), and Mobile.
- **Interactive Elements:** Smooth hover effects and organized FAQ section.

## 🛠️ Tech Stack
- HTML5 / CSS3 (Custom Properties & Flexbox/Grid)
- JavaScript (Responsive logic & interactivity)
- Hosted on: GitHub Pages
